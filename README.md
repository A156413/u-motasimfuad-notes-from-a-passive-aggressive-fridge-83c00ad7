One passive-aggressive note from a smart fridge to its owner. The fridge kept the leftovers cold for six days; the owner ate takeout instead — so the fridge objects to being treated as a museum.

## Run it

```sh
python3 main.py
```

It writes the note to `/output/entry.txt` and prints it on stdout.
